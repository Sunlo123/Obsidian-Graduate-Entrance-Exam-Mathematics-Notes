# 第2讲 数列极限（方法入口）

## 第1课：递推数列极限

| O：遇到什么问题 | P：用什么程序 | D：检查什么 | 链接 |
| --- | --- | --- | --- |
| $x_{n+1}=f(x_n)$，且 $f$ 易于求导 | 求导 → 找统一的常数上界 → 建立压缩估计 | 必须是 $\lvert f'(x)\rvert\le k<1$，$k$ 为固定常数 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#1. 可调用的标准结论\|知识点]] |
| 不便求导，或不易找到压缩常数 | 确定取值范围 → 比较相邻项 → 单调有界 | 压缩法不便使用，不等于数列发散 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#二、单调有界：先定范围，再定方向\|知识点]] |
| 根式之差，变形后容易放缩 | 共轭有理化 → 直接比较 $x_{n+1}$ 与 $x_n$ | 根号有定义；乘除的式子不能为零 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#2. 判断单调性的三种操作\|知识点]] |
| 相邻项相减后易通分、因式分解 | 作差 → 分别判断各因子的符号 | 差式定不了号时，先回头细化 $x_n$ 的范围 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#2. 判断单调性的三种操作\|知识点]] |
| 正项数列，作商后更简单 | 作商 → 与 $1$ 比较 | 先证 $x_n>0$；负项数列的判断方向相反 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#2. 判断单调性的三种操作\|知识点]] |
| 前一问给了不等式，后一问证明收敛 | 相邻项作差定单调；逐项放缩、求和找界 | 对照提示的结构选择变形；双边不等式的两侧可能各有用途 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#五、题设不等式：一边定单调，一边找界\|知识点]] |
| 已证收敛，需要求极限或相邻项比值 | 设极限 → 递推式取极限 → 筛根；比值另作化简 | 连续性、分母、根式符号和单调范围都要检查 | [[AI课程总结/强化篇/高数/第2讲 数列极限/第1课#四、取极限与筛根：先证明存在，再选可行值\|知识点]] |
